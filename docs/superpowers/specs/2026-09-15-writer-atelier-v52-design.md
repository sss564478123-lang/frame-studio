# 작가공방 V52 독립 전문가 패키지 설계

## 목적
V51.1의 의미와 권위 체계를 보존하면서, 기존 문서형 지침에 머문 고급 품질 제어를 실제 패키지 자원으로 구현한다. 결과물은 특정 앱 코드에 의존하지 않는 독립 배포 패키지이며, 총괄 라우터 1개와 전문 스킬 14개를 유지한다.

## 불변 계약
- 사용자 최신 명시 지시 > 승인 본문/최신 확정 설정 > 확정 사건 > 확정 AU > 선택 판본 공식 정사 > 승인 본문 파생 상태 > 현재 장면 제약 > 일반 작법.
- 승인 본문은 파생 장부보다 우선한다.
- 정사와 AU는 별도 층으로 관리한다.
- 정사 기반 장면의 필수 선택값이 없으면 `NO_DRAFT`다.
- 기본 연재 출력은 `본문 전 자료 → 순수 소설 본문 → 본문 후 자료`다.
- 실제 초고 Writer는 `novel-fiction-prose` 하나만 둔다.
- Critic의 실패 taxonomy와 점수는 초고 Writer 문맥에 상시 주입하지 않는다.

## 아키텍처
패키지는 다섯 층으로 구성한다.
1. **라우팅 층**: 요청을 분류하고 필요한 전문 스킬만 선택한다.
2. **전문 스킬 층**: 정사, 캐릭터, 상태, 장면, 대사, 산문, 오리지널, 관계, 개고, 독립 검수, 릴리스, 출력의 14개 책임을 분리한다.
3. **공유 계약/기억 층**: 장면 모멘텀 메모리, 대사 지문, 수정 예산, source-blind 릴리스 계약을 JSON Schema와 한국어 설명으로 제공한다.
4. **분석 도구 층**: 정적 텍스트 분석기는 표현 반복 군집, 문장/문단 리듬, 대사 교대 패턴을 ‘경고 후보’로만 탐지한다. 수치 자체를 문학 품질 판정으로 사용하지 않는다.
5. **검증 층**: 구조 계약 테스트와 held-out 회귀 시나리오를 분리한다.

## V52에서 새로 실체화할 기능
### 1. Phrase Echo Detector
전역 금지어 목록이 아니라 가까운 구간에서 반복되는 문장 시작, 접속 패턴, 행동비트 어휘, 감정 해설 표현, 동일 n-gram을 후보로 찾는다. 자동 수정하지 않고 critic/release에 경고만 제공한다.

### 2. Scene Momentum Memory
장면의 진입 상태, 활성 압력, 미완 행동, 마지막 의미 있는 선택, 정보/관계/물리 변화, 다음 장면으로 넘어가는 추진력을 구조화한다. 플롯 공식이나 cliffhanger 강제 장치가 아니다.

### 3. Dialogue Situational Fingerprint
캐릭터의 ‘평균 말투’ 한 개가 아니라 관계/압력/공개성/피로/목적에 따라 달라지는 발화 길이, 직접성, 질문성, 회피, 침묵, 호칭, 끼어듦 범위를 기록한다. 특정 수치를 반드시 맞추는 생성 목표로 쓰지 않는다.

### 4. Revision Budget Controller
기본 흐름은 초고 → hard 오류 수리 → source-blind 냉독 → 표적 수정 1회 → 재냉독이다. 두 번째 표적 수정은 고영향 문제가 남을 때만 허용한다. 취향 변경이나 ‘더 예쁘게’ 쓰기는 수정 예산을 소모할 근거가 아니다.

### 5. Source-Blind Release Protocol
릴리스 단계는 계획·사용 스킬·검수 로그를 보지 않고 가능한 한 PURE_BODY만 읽는다. 정확한 span, 독자 효과, 최소 수정으로 finding을 제한한다.

### 6. Worst-Case Regression Suite
과묵한 인물, 긴 고백, 친구 농담, 격한 논쟁, 3인 이상 대화, 설명 장면, 전투, 감정 후유증, 정사 캐릭터, 조용한 이동, 부상/물건 이어쓰기, 반복 표현 스트레스를 포함한다. 최상위 회귀는 로봇투, 표현/골격 반복, 중요한 대사의 과압축, 상태 변화 없는 A-B-A-B 교대다.

## 프로젝트 설정
프로젝트 설정은 필요하다. 이유는 재사용 가능한 작법 스킬과 작품별 영구 계약을 분리하기 위해서다. `PROJECT_INSTRUCTIONS_KO.md`는 7,000~8,000자로 유지하고 작법 세부를 중복 복사하지 않는다.

## 사용자 가독성
스킬 ID는 런타임 안정성을 위해 영문 kebab-case를 사용한다. 모든 제목, 설명 본문, 사용 시점, 입력/출력 계약, 판단 절차, 경계, 인계, 완료 기준은 한국어로 작성한다.

## 패키지 배포 구조
`packages/writer-atelier-v52/` 아래에 README, 설치 안내, 프로젝트 설정, 카탈로그, manifest, skills, references, schemas, scripts, evals를 둔다. 기존 V51.1 경로를 수정하지 않는다.

## 성공 기준
- 15개 독립 SKILL.md가 모두 존재하고 구조 검증을 통과한다.
- 프로젝트 설정이 7,000~8,000자다.
- 단일 Writer 및 Writer/Critic 분리 계약이 자동 검증된다.
- 4개 공유 스키마가 JSON Schema로 유효하다.
- 분석 도구는 경고 후보를 출력하되 자동 PASS/FAIL 문학 판정을 하지 않는다.
- held-out 회귀 시나리오가 최소 12개 존재한다.
- 독립 ZIP이 생성되고 무결성 검사가 통과한다.
