# 설치 순서

## 1단계 — 먼저 설치할 12개
`novel-router`, `novel-project-state`, `novel-episode-state`, `novel-canon-research`, `novel-parody-au-architect`, `novel-original-fiction`, `novel-series-architect`, `novel-character-performance`, `novel-scene-architecture`, `novel-dialogue-craft`, `novel-dialogue-floor-control`, `novel-fiction-prose`.

이 12개로 먼저 실제 회차를 테스트한다.

## 2단계 — 대사/장편 강화
`novel-long-speech-craft`, `novel-group-dialogue-orchestration`, `novel-subtext-pressure`, `novel-listener-uptake`, `novel-korean-prose-naturalness`, `novel-emotional-orchestration`, `novel-timeflow-director`, `novel-scene-entry-exit`, `novel-episode-density`.

## 3단계 — 검수
`novel-canon-critic`, `novel-continuity-critic`, `novel-structure-critic`, `novel-first-reader`, `novel-longterm-reader`, `novel-devils-advocate`, `novel-chief-editor`.

## 4단계 — 나머지 Core 및 Optional
장르와 작품에 맞게 설치한다. 미스터리면 `novel-mystery-fair-play`, 전투물이면 `novel-action-choreography`, 다중 POV면 `novel-multi-pov-director`를 추가한다.

## 기존 거대 `writer-atelier-sovereign-studio`
새 독립 Skill 세트로 실제 1~2회차가 정상 동작하는 것을 확인한 뒤 삭제한다. 현재 정상 동작 중인 `novel-*` 개별 Skill은 같은 이름의 새 버전으로 교체할 때까지 유지한다.
