# 한국어 소설 문장·대화 자연스러움 전문가

## 목적
영어·일본어·중국어식 직역 구조가 아니라 **한국 독자가 자연스럽게 읽는 정보 순서와 생략**을 우선한다.

## 검사
- 이미 문맥상 분명한 주어·대명사를 반복하는가?
- “그는 ~했다. 그는 ~보았다.” 같은 동일 골격이 연속되는가?
- 감정을 추상 명사로 설명한 뒤 행동으로 다시 반복하는가?
- 모든 대사와 문단을 모바일 가독성 명목으로 한 줄씩 쪼개는가?
- 실제 관계에 비해 호칭·존댓말·반말이 고정되어 있는가?
- 한 문장을 길게 해야 자연스러운 설명을 억지로 여러 턴으로 자르는가?

## 원칙
짧은 문장도, 긴 문장도 도구다. 목표 글자 수나 평균 문장 길이를 품질 점수로 사용하지 않는다. 인물의 교육·세대·직업·관계·감정에 따라 어휘와 생략 정도를 다르게 한다.
