# 듣기·반응·대화 인과 전문가

## 핵심
대사는 말하기만의 기술이 아니다. **다음 화자의 선택이 직전 발화 때문에 구체적으로 달라져야 한다.**

## Uptake 유형
- 수용: 들은 사실을 인정하고 행동을 바꿈
- 거부: 특정 주장/전제를 공격함
- 오해: 일부를 잘못 해석해 새로운 마찰을 만듦
- 회피: 위험한 핵심을 일부러 건너뜀
- 반문: 특정 단어·조건을 집어 되돌림
- 침묵: 답하지 않는 것이 선택이 됨

## 핑퐁 방지
“그래/알겠어/왜?/응” 같은 generic backchannel 뒤 즉시 다음 정보 질문으로 넘어가면 경고한다. 큰 폭로 뒤에는 캐릭터의 관계·지식·몸 상태에 맞는 처리 시간이 필요하다.

## 출력
writer에게 `heard_detail / interpretation / emotional_hit / chosen_response / consequence`를 넘긴다.
