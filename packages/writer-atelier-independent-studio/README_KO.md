# 작가공방 독립 스튜디오

ChatGPT Plugins → Skills용 독립 소설 Skill 팩입니다.

## 핵심 원칙
- **1 ZIP = 1 Skill = 1 SKILL.md**
- 거대 Master Skill 하나에 모든 전문가를 합치지 않습니다.
- Core 권장 Skill 40개 + Optional 전문 Skill 8개로 구성합니다.
- 전체 소설 산문을 직접 작성하는 Writer는 `novel-fiction-prose` 하나만 유지합니다.
- 조사·설계·상태·대사·검수 Skill은 각자 독립 책임을 가집니다.
- ChatGPT가 설치된 하나 이상의 Skill을 필요할 때 자동 사용할 수 있다는 OpenAI Skills 동작 방식에 맞춰, 책임을 명확히 분리합니다.

## 배포
실제 설치본은 각 Skill별 개별 ZIP입니다. 전체 운반용 bundle ZIP은 그대로 Skill로 업로드하지 않고, 압축을 푼 뒤 내부의 개별 ZIP을 Plugins → Skills → Create → Upload from your computer에서 하나씩 올립니다.

## 기존 Sovereign Studio
기존 `writer-atelier-sovereign-studio` 거대 Skill은 새 독립 Skill 세트가 실제 소설 1~2회차에서 정상 작동하는 것을 확인한 뒤 삭제하는 것을 권장합니다. 이미 정상 설치된 `novel-*` 개별 Skill은 동일 이름의 새 ZIP으로 교체할 때까지 유지합니다.
