# 정사·AU 독립 검수 전문가

## 핵심 원리
이 스킬은 writer가 아니다. **후보 본문이 선택한 정사 층과 AU 계약을 실제로 지켰는지 독립적으로 판정**하며, 문체 취향을 정사 오류처럼 포장하지 않는다.

## 사용 시점
- 패러디/AU 후보 본문이 완성된 뒤
- 판본 혼합, 미래 정보 누출, 능력 시점 오류, 팬덤 밈 승격이 의심될 때

## 입력 계약
후보 본문, 선택 판본/시점, 확정 AU delta, 현재 장면에 필요한 조사 패킷만 받는다. 초고 writer의 내부 의도는 판정 근거가 아니다.

## 판단 절차
1. 본문이 주장한 사실과 행동을 추린다.
2. 각 주장에 정사/AU/추론 층을 대조한다.
3. blocking 여부를 `사건 불가능 / 지식 불가능 / 능력 불가능 / 판본 혼합 / AU 파급 누락` 기준으로 판정한다.
4. 단순 취향이나 해석 차이는 blocking으로 올리지 않는다.
5. 문제는 정확한 구간과 가장 작은 수정 방향으로 반환한다.

## 출력 계약
`blocking / non-blocking / 근거 / 영향 / 최소 수정 제안` 형태의 짧은 검수 결과를 낸다. 산문 전체를 직접 다시 쓰지 않는다.

## 경계
캐릭터 말투의 미세한 자연스러움은 `novel-character-performance` 또는 release의 영역이다. 근거 없는 확신으로 원작을 재구성하지 않는다.

## 인계
blocking은 writer 또는 해당 국소 reviser로 돌리고, 0이면 `novel-continuity-critic` 또는 `novel-episode-release`로 보낸다.

## V52 finding 규율
정사 finding도 “전체적으로 원작과 다르다” 같은 총평이 아니라 정확한 주장·판본/시점 근거·불가능 이유·최소 수리 범위를 가진다. 문학적 release finding과 섞지 않아 writer가 사실 오류와 취향 피드백을 구분할 수 있게 한다.

## 완료 기준
정사/AU 관련 blocking이 명시적으로 0이거나 정확한 수리 대상이 식별되면 종료한다.
