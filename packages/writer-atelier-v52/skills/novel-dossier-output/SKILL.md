# 회차 자료·출력 편집 전문가

## 핵심 원리
독자는 소설 본문을 읽고, 제작 정보는 본문 밖에서 본다. **작품 세계와 제작 메타를 완전히 분리**하면서 다음 회차에 필요한 상태는 손실 없이 보존한다.

## 사용 시점
- 한 회차를 최종 사용자에게 전달할 때
- 정사/AU/상태 자료를 PRE/POST에 배치해야 할 때
- 긴 회차 후 다음 화 인계 상태를 정리할 때

## 입력 계약
릴리스 통과 후보 본문, 이번 회차에 실제 사용한 핵심 전제, 최종 본문에서 확정된 상태 변화만 받는다.

## 판단 절차
1. 사용자 출력 요청이 `전체 회차`인지 `본문만`인지 확인한다.
2. 전체 회차면 PRE에는 읽기 전에 필요한 최소 자료만 둔다.
3. PURE_BODY에는 이야기 세계 내부 내용만 둔다.
4. POST에는 최종 본문에서 실제 발생한 변화, 남은 미완 사건, 다음 화에 영향을 주는 상태만 둔다.
5. 초안에서 사라진 설정이나 검수 중 가정은 POST로 올리지 않는다.

## 출력 계약
기본 형식은 `본문 전 자료 → 순수 소설 본문 → 본문 후 자료`. `본문만/소설만/PROSE_ONLY` 요청에서는 PURE_BODY만 출력한다.

## 경계
PRE/POST를 설정 백과나 검수 보고서로 부풀리지 않는다. 본문 안에 출처·검색·스킬·점수·상태표를 삽입하지 않는다.

## 인계
POST의 최종 상태만 다음 회차 `novel-episode-state`의 입력 후보가 된다. 실제 정본 승격은 사용자 승인 후 이뤄진다.

## V52 다음 화 인계
POST에는 필요할 때 Scene Momentum의 carry-forward를 자연스러운 한국어로 압축해 포함할 수 있다. 그러나 schema 필드명이나 내부 검수 로그를 사용자 본문에 노출하지 않는다. 다음 화 인계는 최종 후보에서 실제로 생긴 변화만 다룬다.

## 완료 기준
본문과 제작 메타가 섞이지 않고, 다음 회차에 필요한 확정 상태가 최종 후보에서만 수확되면 종료한다.
