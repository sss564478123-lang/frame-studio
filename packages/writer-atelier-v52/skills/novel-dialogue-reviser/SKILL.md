# 대사 국소 개고 전문가

## 핵심 원리
대사를 “더 길게” 또는 “더 인간적으로” 만드는 것이 목적이 아니다. **확인된 실패 구간의 상호작용 구조만 최소 수정**하고 작동하는 비대칭과 캐릭터 리듬은 보존한다.

## 사용 시점
- 완성본 냉독에서 대사 문제가 구체적 구간으로 확인됐을 때
- 중요한 발화가 여러 한 줄로 잘렸거나 상대의 구체적 uptake가 빠졌을 때
- 태그를 가리면 화자가 모두 같은 사람처럼 보일 때

## 입력 계약
완성된 전체 장면, 문제 span, 독자 효과, 캐릭터 수행 프로필, 사실·정사·상태 제약을 받는다. 부분만 보고 전체 대화를 재설계하지 않는다.

## 판단 절차
1. 전체 대화를 한 번 읽고 문제 구간의 기능을 확인한다.
2. 결함이 `발언권 파편화 / uptake 부족 / 동일 음성 / 정보 강의 / 장식 행동비트 / 기계적 교대` 중 무엇인지 진단한다.
3. 가장 작은 수정 방법을 고른다: 합치기, 반응 선택 바꾸기, 한 발화 확장, 불필요한 비트 제거, 호칭/register 복원.
4. 수정 구간을 전체 맥락에서 다시 읽는다.

## 출력 계약
전체 장면을 새로 쓰지 않고 필요한 span만 교체한다. 사용자가 전체 수정본을 요청하면 교체 결과를 반영한 전체 본문을 반환할 수 있다.

## 경계
짧은 답을 일괄 팽창시키지 않고, 모든 줄에 행동을 붙이지 않고, 고유한 어색함·침묵·장문을 자동 정규화하지 않는다.

## 인계
대사 수정 후 문단 리듬이나 산문 반복이 남을 때만 `novel-prose-reviser`로 넘긴다. 마지막 판정은 `novel-episode-release`가 한다.

## V52 수정 예산
이 스킬은 `Revision Budget`의 표적 수정 1회를 소모하는 작업일 수 있다. 먼저 finding의 정확한 span과 독자 효과가 있어야 한다. 고칠 근거가 사라졌다면 남은 예산이 있어도 사용하지 않는다. 수정 후 같은 구간만 보지 말고 전체 교환을 다시 읽는다.

## 완료 기준
원래 문제의 독자 효과가 사라지고 캐릭터 음성·사실·장면 인과가 보존되면 종료한다.
