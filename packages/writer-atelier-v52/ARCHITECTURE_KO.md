# V52 아키텍처

V52는 `라우터 → 필요한 조사/상태/설계 전문가 → 단일 Writer → 독립 hard critic → 필요한 국소 reviser → source-blind release → dossier`의 단방향 기본 흐름을 사용한다.

공유 상태는 Writer의 자유를 침해하지 않도록 **사실, 범위, 인계 계약**만 제공한다. `scene-momentum`은 장면을 정해진 공식으로 찍어내지 않고 이전 선택의 관성을 보존한다. `dialogue-fingerprint`는 캐릭터를 평균 수치 하나로 환원하지 않고 관계와 압력별 범위를 기록한다. `revision-budget`은 고칠수록 모두 같은 문체가 되는 과개고를 막는다. `release-finding`은 문제를 정확한 span과 독자 효과로 제한해 “느낌상 전부 다시 써라”를 금지한다.
