# V52 Source-Blind 릴리스 프로토콜

## 목적
구조 검사와 정적 분석이 모두 통과해도 실제 본문이 기계적으로 읽힐 수 있다. 릴리스 단계는 제작 노트를 보지 않고 가능한 한 PURE_BODY만 읽어 실제 독자 효과를 확인한다.

## 순서
1. 첫 독서는 표시 없이 끝까지 읽는다.
2. 정사/AU/연속성 hard blocking은 별도 critic 결과로 이미 0이어야 한다.
3. 냉독에서는 로봇투, house voice 평준화, 중요한 발화의 과압축, 상태 변화 없는 교대, 설명 재진술, 반복 골격 군집을 본다.
4. finding은 정확한 span, 독자 효과, 최소 수정으로 기록한다.
5. 수정 예산을 확인하고 필요한 국소 reviser 하나만 호출한다.
6. 재냉독 후 고영향 문제가 없으면 멈춘다.

## 자동 분석과의 관계
`analyze_passage.py`의 결과는 **확인 후보 목록**이다. 후보가 있어도 문맥상 의도된 반복이면 보존할 수 있고, 후보가 없어도 실제 냉독이 기계적이면 REPAIR가 가능하다. 정적 도구는 독자를 대체하지 않는다.

## PASS 조건
하드 blocking 0, source-blind 냉독의 고영향 finding 0, 추가 수정이 주로 취향 차이거나 고유 음성을 평준화할 위험이 큰 상태.
