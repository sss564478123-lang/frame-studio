# 설계 참고 기록

V52는 공개된 소설 작법/에이전트 스킬의 구조 원리를 참고했지만 문구를 통째로 이식하지 않는다.

- SkillMedev Fiction Scene Writer: 장면을 실시간 선택과 변화로 다루고 감각을 목록이 아니라 선택적으로 사용하는 원리.
- SkillMedev Ghostwriter: 매끈한 기본 house voice가 개별 음성을 지우는 위험과 고유 리듬 보존 원리.
- SkillMedev Manuscript Reviser: 전체 passage를 먼저 읽고 coarse-to-fine으로 수정하며 이미 작동하는 부분을 건드리지 않는 원리.
- jwynia Dialogue: Text/Subtext/Context 층, 동일 음성, 정보 전달형 대사, Tennis Match식 균등 교대 진단 원리.
- Superpowers writing-skills: 스킬을 사용 조건으로 발견시키고, 책임 경계와 테스트를 먼저 고정하는 원리.

외부의 수치 임계값이나 특정 작법 규칙은 보편 법칙으로 채택하지 않는다. V52의 정적 분석 결과는 경고 후보일 뿐 자동 품질 판정이 아니다.
