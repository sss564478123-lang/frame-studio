# 장면 모멘텀 메모리

## 목적
장면 모멘텀은 “다음 화에 무슨 사건을 넣을지”가 아니라 **직전 장면에서 생긴 선택의 관성과 아직 끝나지 않은 압력**을 기억한다. 장면 전환 때 감정·미완 행동·권력 변화가 리셋되는 문제를 막는다.

## 기록 단위
- 진입 상태: 장면 시작 시 이미 존재한 압력과 제약
- 활성 압력: 지금 선택을 좁히는 사람/환경/시간/비밀
- 미완 행동: 시작했지만 끝나지 않은 행동·대화·약속
- 마지막 의미 있는 선택: 장면의 방향을 실제로 바꾼 선택
- delta: 정보, 관계, 권력, 감정, 물리 상태의 변화
- 출구 벡터: 다음 장면에서 자연스럽게 이어질 가능성

## 사용 규칙
이 메모리는 장면에 cliffhanger를 강제하지 않는다. 조용한 장면도 오해가 깊어지거나 관계가 조금 바뀌거나 실무 상태가 바뀌면 충분하다. Writer에게는 현재 장면에 영향을 주는 항목만 전달한다.
