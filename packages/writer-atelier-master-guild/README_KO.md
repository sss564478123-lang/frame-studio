# 작가공방 마스터 길드
## Writer Atelier Master Guild

장편·웹소설·패러디·AU·크로스오버·오리지널 소설을 위한 **30개 독립 Agent Skill + 10개 편집 에이전트** 패키지다.

핵심 목표는 스킬 수를 늘리는 것이 아니라, **20년차 작가의 장기 설계 감각과 전문 편집실의 다중 검수를 분리된 역할로 재현**하는 것이다.

### 핵심
- 총 30개 Skill
- 신규 거시 전문 Skill 15개
- 9개 독립 검수 에이전트 + 편집장 1개
- 유일한 전체 산문 Writer: `novel-fiction-prose`
- 패러디/AU consequence cascade
- crossover bridge rules
- 장편 3개 계획 지평: Series / Arc / Episode
- 복선·서사 약속 lifecycle
- 다중 POV knowledge firewall
- 감정 파형과 장기 잔여 상태
- 독립 editorial council
- 30개 이상 held-out 회귀 시나리오
- 프로젝트 고정 계약 7,000~8,000자

`INSTALL_KO.md`, `SKILL_CATALOG_KO.md`, `AGENT_CATALOG_KO.md`, `council/EDITORIAL_COUNCIL_KO.md`부터 읽으면 된다.
