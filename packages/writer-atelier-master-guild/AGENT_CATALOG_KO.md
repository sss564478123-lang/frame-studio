# 편집 에이전트 카탈로그

| 에이전트 | 관점 |
|---|---|
| 정사·AU 감수 에이전트 | 정사 기반 패러디·AU·크로스오버에서 사실, 판본, 시점, AU delta와 파급을 검수한다. |
| 구조·페이싱 개발편집 에이전트 | 장면과 회차가 무엇을 바꾸는지, 장편 아크가 진행되는지, 복선과 회수의 위치가 기능하는지 본다. |
| 캐릭터·대사 연기감독 에이전트 | 인물이 관계와 상황에 맞게 행동·말하는지, 대사가 의미를 완료하고 구체적으로 반응하는지 본다. |
| 연속성·세계 논리 감수 에이전트 | 시간·위치·부상·물건·지식·능력·세계 규칙과 인과를 점검한다. |
| 신규 독자 냉독 에이전트 | 배경 설명 없이 처음 읽는 독자의 관점에서 이해도, 몰입, 감정 전달, 지루함을 본다. |
| 장기 독자·팬 관점 에이전트 | 이전 회차를 기억하는 장기 독자 관점에서 반복, 약속 방치, 관계·감정 리셋, 누적 보상을 본다. |
| 연재 리듬·다음화 기대 편집 에이전트 | 웹연재 관점에서 한 회차의 국소 만족과 다음 회차를 읽을 이유가 균형을 이루는지 본다. |
| 한국어 문체·라인 편집 에이전트 | 자연스러운 한국어, 서술 음성, 반복 골격, 과설명, 나열체, 번역투를 검수한다. |
| 악마의 변호인·레드팀 에이전트 | 다른 검수자가 놓치기 쉬운 가장 그럴듯한 반론을 찾고, 작품이 쉬운 선택이나 작가 편의에 기대는 지점을 공격한다. |
| 편집장·합의 조정 에이전트 | 독립 검수 결과를 합쳐 사실 오류·독자 효과·보존가치·수정비용을 비교하고 실제 수정 여부를 결정한다. |

에이전트는 실제 사람이 아니라 서로 다른 편집 관점을 강제 분리하는 역할 정의다.
