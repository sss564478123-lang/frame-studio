# 작가공방 마스터 길드 — 전체 아키텍처

`Router → 선택적 거시 전문가 → 장면 전문가 → Single Writer → 독립 편집위원회 → 국소 수리 → Source-Blind Release → Dossier`

## 1. 선택적 거시 전문가
시리즈·장르·아크·복선·AU·크로스오버·POV·세계관 등 요청의 해상도에 필요한 스킬만 로드한다.

## 2. 장면 실행 계층
정사, 캐릭터 수행, 상태, 장면, 대사가 현재 장면에 필요한 사실과 제약을 만든다.

## 3. 단일 Writer
`novel-fiction-prose`만 전체 산문을 작성한다. 여러 Writer가 같은 원고를 순차적으로 덮어쓰지 않는다.

## 4. 독립 편집위원회
9개 검수 역할이 서로의 의견을 보기 전에 각자 읽는다. 입력 정보량도 관점별로 다르다. 편집장이 finding만 받아 충돌을 조정한다.

## 5. 수정 예산
hard fact → continuity → reader-blocking → local prose 순으로 최소 수정한다. 취향 수준이면 멈춘다.
