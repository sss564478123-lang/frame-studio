# 작가공방 V53 — 전체 스킬 원문 보기

> 이 파일은 GitHub에서 15개 스킬을 한 페이지로 검토하기 위한 **읽기 전용 미러**다. 실제 설치 구조는 `skills/<skill-name>/SKILL.md`로 분리되어 있으며 이 문서를 하나의 스킬로 설치하지 않는다.

실제 설치/배포용 원문은 이 패키지의 `skills/` 아래 15개 독립 디렉터리에 각각 존재한다. 한국어 스킬 목록과 역할은 `SKILL_CATALOG_KO.md`, 실행 순서는 `RUNTIME_FLOW_KO.md`, 프로젝트 고정 설정은 `PROJECT_INSTRUCTIONS_KO.md`를 확인한다.
