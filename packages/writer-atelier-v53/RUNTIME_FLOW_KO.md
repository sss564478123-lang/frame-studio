# 작가공방 V53 런타임 흐름

## 정사 기반 새 회차
`novel-router → canon-research → character-performance → episode-state → scene-architecture → dialogue-craft(필요 시) → fiction-prose → canon-critic + continuity-critic → episode-release → 필요한 reviser 1회 → 재냉독 → dossier-output`

## 오리지널 회차
`novel-router → original-fiction → episode-state → scene-architecture → character-performance → dialogue-craft(필요 시) → fiction-prose → continuity-critic → episode-release → 필요한 reviser → dossier-output`

## 핵심 규칙
초고 전에 critic을 활성화하지 않는다. 모든 전문 스킬을 매번 로드하지 않는다. `fiction-prose`만 전체 산문을 쓴다. reviser는 완성본에서 실제로 확인된 구간만 수리한다. 최종 냉독은 가능하면 PURE_BODY를 먼저 읽고 그 다음에만 정적 분석 후보를 확인한다.

## 장기 연재
`episode-state`는 승인 본문을 기준으로 상태와 장면 관성을 수확한다. `character-performance`의 대사 지문은 관계·압력·공개성·몸 상태별 범위로만 사용하며 숫자 할당량으로 쓰지 않는다.
