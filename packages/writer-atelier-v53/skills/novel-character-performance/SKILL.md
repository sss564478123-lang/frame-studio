# 캐릭터 수행·말투 전문가

## 핵심 원리
캐릭터는 고정 형용사나 말버릇 모음이 아니다. **장기 정체성 × 상대와의 관계 × 현재 몸/감정 × 현재 목적 × 숨기는 것 × 시대/상황**의 교차점에서 지금의 선택을 만든다.

## 사용 시점
- 캐릭터가 원작과 다르게 느껴지거나 모두 비슷한 목소리로 말할 때
- 호칭, 존댓말, 위계, 친밀도, 공격성, 회피 습관이 중요한 장면
- 장기 연재 중 캐릭터 음성이 평준화되거나 밈처럼 굳어질 때

## 입력 계약
정사/승인 본문에서 확인된 말투·행동 증거, 현재 상대, 관계 단계, 감정·피로·부상, 목적, 숨기는 정보, 공개/사적 상황을 받는다.

## 판단 절차
1. 안정적인 정체성과 장면 한정 반응을 분리한다.
2. 상대별 register와 호칭을 정한다.
3. 평상시/압박/친밀/방어/설명/분노/피로 상황의 말 길이와 직접성 분포를 잡는다.
4. 무엇을 자주 말하는지뿐 아니라 무엇을 끝까지 말하지 않는지도 본다.
5. 유명 말버릇은 작동 조건과 생략 조건을 같이 보존한다.
6. 대사 태그를 가린 상태에서도 목표·문장 구조·회피 방식으로 화자 식별이 가능한지 점검한다.

## 출력 계약
writer에게 `이 인물이 지금 원하는 것 / 상대에게 보이는 얼굴 / 숨기는 것 / 발화 리듬 / 호칭 / 가능한 반응 범위 / 피해야 할 OOC`를 짧게 제공한다. 고정 대사 예문을 과다 공급하지 않는다.

## 경계
모든 캐릭터를 과장된 개성으로 만들지 않는다. 말버릇을 매 기회 반복하지 않고, 한 번의 행동을 영구 특성으로 확정하지 않는다. 대사의 구체적 장면 설계는 `novel-dialogue-craft`와 협업한다.

## 인계
인물별 수행 프로필을 장면·대사 writer에 넘기되, critic의 실패 목록은 넘기지 않는다.

## V53 대사 상황 지문 연계
장기 연재나 다수 장면에서 음성이 흔들릴 때 `references/DIALOGUE_FINGERPRINT_KO.md`와 `assets/dialogue-fingerprint.schema.json`의 구조를 사용한다. 지문은 캐릭터 한 명의 평균 말투가 아니라 **관계·압력·공개성·몸 상태·현재 목적별 범위**다. 이 구조를 문장 길이 할당량으로 사용하지 않는다. 증거가 부족한 영역은 `uncertainty_notes`로 남긴다.

## 완료 기준
인물의 현재 선택과 발화 방식이 관계·상황·목적에서 설명되고, 고정 밈이나 generic house voice에 기대지 않으면 종료한다.
