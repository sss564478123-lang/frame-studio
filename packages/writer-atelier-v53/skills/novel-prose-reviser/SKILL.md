# 산문 국소 개고 전문가

## 핵심 원리
퇴고는 새 글쓰기 대회가 아니다. **이미 작동하는 음성·리듬·비대칭은 보호하고, 확인된 독서 장애만 가장 작은 범위에서 고친다.**

## 사용 시점
- 후보 본문이 이미 존재할 때
- 냉독에서 특정 문단의 나열체·반복·과설명이 확인됐을 때
- 사실/POV 오류를 고친 뒤 문장 연결만 정리할 필요가 있을 때

## 입력 계약
전체 후보 본문, 문제 구간, 독자에게 생긴 효과, 보호해야 할 POV·시제·서술 거리·캐릭터 음성·정사/AU를 받는다.

## 판단 절차
1. 수정 전 전체 passage를 한 번 읽는다.
2. 사실·POV·인과 오류가 있으면 문체보다 먼저 해결됐는지 확인한다.
3. 문제를 `반복 골격 / 카드식 나열 / 감정 재설명 / 동일 house voice / 부자연스러운 연결 / 과도한 수식`처럼 구체화한다.
4. 문제 span만 고친다.
5. 앞뒤 문맥에서 새 반복이나 음성 평준화가 생기지 않았는지 다시 읽는다.

## 출력 계약
수정 이유가 correctness, clarity, causality, continuity, voice, pacing, reader effect 중 하나와 연결되어야 한다. 단지 더 예쁘게 바꿀 수 있다는 이유로 문장을 교체하지 않는다.

## 경계
의도된 반복·평범한 문장·파편문·긴 문장·주저함을 자동 제거하지 않는다. 전체 장면을 자신의 문체로 덮어쓰지 않는다.

## 인계
대사 구조 결함은 `novel-dialogue-reviser`, 최종 독서 판정은 `novel-episode-release`에 넘긴다.

## V53 Phrase Echo와 수정 예산
`analyze_passage.py`가 반복 후보를 반환해도 자동 수정하지 않는다. 의도된 모티프·캐릭터 반복·리듬 반복인지 문맥에서 먼저 확인한다. 실제 독서 장애로 확인된 span만 `Revision Budget` 안에서 수리하고, 단어만 동의어로 바꿔 동일 문장 골격을 숨기는 식의 표면 수정은 피한다.

## 완료 기준
지적된 독서 문제가 해결되고, 수정 전의 고유 음성과 의미가 유지되며, 추가 변경이 취향 차이에 가까워지면 종료한다.
