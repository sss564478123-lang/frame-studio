# 수정 예산 계약

## 목적
좋은 초고가 여러 전문가의 연속 개고를 거치며 평준화되는 문제를 막는다.

## 기본 흐름
`초고 → hard 오류 수리 → source-blind 냉독 → 표적 수정 1회 → 재냉독`.

두 번째 표적 수정은 **고영향 문제가 실제로 남았을 때만** 허용한다. 정사/연속성 hard 오류 수정은 문학적 취향 수정과 별개로 취급한다.

## 수정 근거가 되는 것
사실 오류, POV 불가능, 인과 단절, 독자 이해를 깨는 모순, 뚜렷한 house voice 붕괴, 발언권 파편화, 반복 골격 군집, 보여준 의미의 즉시 재설명.

## 수정 근거가 아닌 것
“다르게 쓸 수도 있다”, “더 문학적으로 보일 수 있다”, “모든 문장을 더 세련되게 만들고 싶다”. 작동하는 평범한 문장과 불균형은 보존 대상이다.
