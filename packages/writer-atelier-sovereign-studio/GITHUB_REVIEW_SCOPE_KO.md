# GitHub 검토 범위

이 브랜치는 **검토와 유지보수에 필요한 문서·프로젝트 계약·50개 Skill 카탈로그·18개 Agent 전체 원문·핵심 신규 Skill 원문·상태 스키마·GitHub 연구 provenance**를 소스 형태로 제공한다.

실제 설치/배포 정본은 `Writer_Atelier_Sovereign_Studio_FINAL.zip`이다. 최종 ZIP 내부에는 50개 Skill이 각각 `skills/<skill-id>/SKILL.md`에 독립 배치되고, 18개 Agent도 `agents/` 아래 개별 파일로 유지된다. 또한 전체 Skill ZIP, Agent ZIP, 개별 Skill ZIP 50개를 포함한다.

GitHub 검토 브랜치에 전체 배포 ZIP 바이너리를 넣지 않은 이유는 diff 가독성과 저장소 유지보수성을 보존하기 위해서다. PR의 `VALIDATION_KO.md`는 최종 ZIP을 만든 로컬 정본에서 수행한 검증 결과다.
