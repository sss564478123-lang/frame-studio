# Writer Atelier Sovereign Studio

## 목적
이 스킬은 한국어 장편 소설, 웹연재, 오리지널, 패러디·팬픽, AU, 크로스오버를 **한 명의 최종 Writer와 여러 전문 참조 모듈·독립 검수 관점**으로 운영한다. 사용자가 전문가를 직접 고르지 않아도 현재 요청의 위험과 범위를 판단해 필요한 참조만 불러온다.

## 절대 운영 원칙
1. 전체 산문을 최종적으로 쓰는 역할은 하나다. 여러 리뷰어가 같은 본문을 차례대로 전면 재작성하지 않는다.
2. 사용자 최신 지시와 승인 본문이 오래된 계획보다 우선한다.
3. 패러디/AU는 정사와 AU delta를 분리한다. AU 결과로 전제가 사라진 원작 사건을 억지로 재연하지 않는다.
4. 제한 POV에서는 다른 인물의 내면을 사실처럼 단정하지 않는다.
5. 장면 상태, 부상, 피로, 소지품, 지식, 오해, 관계, 약속, 감정 잔여는 장면 전환으로 초기화하지 않는다.
6. 초고 Writer에게 실패 체크리스트를 과도하게 노출하지 않는다. 검수는 초고 뒤에 한다.
7. 문학적 취향과 사실·연속성 오류를 구분한다.
8. 소설 본문에는 스킬명, 검색, 출처, AI, 검수 로그 같은 제작 메타를 넣지 않는다.

## 자동 라우팅
먼저 사용자 요청을 분류하고 필요한 참조만 읽는다.

### 정사·패러디·AU
- canon research
- parody/AU architecture
- 필요 시 crossover harmonization
- 정사 오류 위험이 높으면 canon/AU auditor

### 오리지널 장편·세계관
- original fiction
- series architecture
- world systems
- 필요 시 character/relationship/theme 전문가 추가

### 다음 화·이어쓰기
- episode state
- scene architecture
- consequence memory
- 최근 승인 본문에서 실제 상태를 수확

### 대사가 짧은 핑퐁·전부 한 줄이라는 피드백
1. dialogue craft
2. dialogue floor control
3. dialogue length dynamics
4. 긴 고백·설명·협상은 long speech craft
5. 3명 이상이면 group dialogue orchestration
6. 숨은 뜻 문제가 있으면 subtext pressure
7. 완성 후에만 dialogue floor editor로 냉독

## 대사 기본 계약
- **한 문장짜리 턴을 연속 기본값으로 만들지 않는다.**
- 설명·고백·설득·협상·거절·회상처럼 하나의 발화 행위가 여러 문장을 필요로 하면, 화자가 의미를 끝낼 만큼 발화권을 유지하게 한다.
- 상대가 실제로 끊을 이유가 있을 때만 끼어듦을 사용한다. 문장 수 때문에 턴을 넘기지 않는다.
- 짧은 대사는 금지하지 않는다. 충격, 명령, 거절, 회피, 과묵함, 긴급성처럼 짧음이 행동일 때 쓴다.
- 같은 장면에서 모든 인물의 대사 길이를 맞추지 않는다. 관계·권력·정보량·감정 통제에 따라 길이가 달라진다.
- 긴 발화는 따옴표 안의 설명문이 아니다. 주장, 기억, 감정, 회피, 조건 등 내부 방향이 움직여야 한다.
- 같은 화자의 하나의 의미 단위는 필요하면 여러 문장으로 한 대사 블록에 둔다. 모바일 가독성을 이유로 전부 한 줄 문단으로 쪼개지 않는다.
- A/B/A/B 자체가 오류가 아니라, 압력·목표·정보·감정·권력 변화 없이 같은 크기의 질문/답변이 반복되는 것이 오류다.

## 장면 작성 절차
1. 현재 정본과 사용자 목표를 확정한다.
2. 현재 장면을 바꾸는 사실만 불러온다.
3. POV 인물의 목표, 즉시 압력, 관계, 숨긴 정보, 몸 상태를 정한다.
4. 장면이 끝날 때 무엇이 달라져야 하는지 정한다.
5. 대화가 있다면 화자별 speech act와 발화권을 설계한다.
6. 한 명의 Writer가 장면 전체를 통합해 쓴다.
7. 정사/연속성 같은 하드 오류부터 검수한다.
8. 필요한 경우에만 독립 독자 관점을 골라 냉독한다.
9. 실제 고영향 문제만 국소 수정한다.
10. 최종 승인 본문에서 다음 회차 상태를 수확한다.

## 다중 검수 원칙
검수자는 서로의 finding을 보기 전에 독립적으로 읽는다. 일반 회차에 모든 검수자를 호출하지 않는다. 신규 독자, 장기 팬, 정사/AU, 연속성, 구조/페이싱, 대사/캐릭터, 발화권, 장문 대사, 다인 대화, 서브텍스트, 몰입/호흡, 적대자 지능, 악마의 변호인 중 필요한 관점만 선택하고 마지막에 편집장이 충돌을 정리한다.

편집장은 다수결을 하지 않는다. 근거, 독자 영향, 사실성, 보존 가치, 수정 범위, 신뢰도를 기준으로 판단한다.

## 출력
사용자가 별도 형식을 지정하지 않은 연재 회차는 기본적으로:
1. 본문 전 자료 — 필요한 최소 전제
2. 순수 소설 본문
3. 본문 후 자료 — 실제로 바뀐 상태와 열린 문제

사용자가 “본문만/소설만”을 요구하면 본문만 출력한다.

## 종료 기준
정사/AU/POV/지식/연속성의 blocking 오류가 없고, 냉독에서 고영향 로봇투·동일 음성·무변화 핑퐁·중요 발화 파편화·설명 재진술이 남지 않으면 멈춘다. “더 다르게 쓸 수 있다”만 남았으면 더 고치지 않는다.
