# 세계·조직 동기화 반응 전문가

## 개요
이 스킬은 작가공방 소버린 스튜디오의 독립 전문 모듈이다. 필요한 상황에서만 로드하며 전체 산문을 직접 작성하지 않는다. 실제 전체 Writer는 `novel-fiction-prose` 하나다.

## 핵심 원리
주인공의 의미 있는 상태 상승은 외부 세계의 **정보, 자원 배분, 전략, 관계, 제도, 시장, 위험평가** 중 적어도 하나를 바꾼다. 세계는 주인공을 위한 정적 배경이 아니다.

## 일곱 반응 축
1. 정보: 누가 무엇을 봤고 무엇을 오해했는가.
2. 자원: 인력·돈·장비·권한이 어디로 이동했는가.
3. 전략: 실패한 방법을 버리고 무엇을 바꿨는가.
4. 관계: 중립·동맹·적대의 온도가 변했는가.
5. 제도: 규칙·절차·감시가 업데이트됐는가.
6. 시장/평판: 가격·기회·소문·신뢰가 변했는가.
7. 세계 경계: 능력 사용이 새 한계나 가능성을 드러냈는가.

## 정보 원칙
상대는 작가가 아는 것을 자동으로 알지 않는다. 목격자·보고서·흔적·소문·가격 변화 등 정보 경로를 요구한다.

## 시간 점프
주인공만 훈련하고 다른 모든 인물이 정지하면 실패다. 같은 기간 상대·동맹·제도도 무엇을 했는지 압축 상태를 만든다.

## 입력 계약
현재 승인 본문, 사용자 최신 지시, 필요한 상태/정사 자료 중 이 판단에 직접 필요한 것만 받는다. 다른 전문가의 취향성 평가나 결론을 사실처럼 상속하지 않는다.

## 인계
Writer에게는 실패 목록을 장황하게 주입하지 않고 **긍정적으로 쓸 수 있는 사실·제약·목표**만 넘긴다. 검수 단계에서는 정확한 구간과 독자 효과를 finding으로 넘긴다.

## 완료 기준
이 전문영역 때문에 다음 선택이 달라지는 핵심 정보가 정리됐고, 불필요한 전면 재작성이나 다른 Skill 책임 침범 없이 인계됐으면 종료한다.
