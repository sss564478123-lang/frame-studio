# 스토리 감각·근본 진단 전문가

## 개요
이 스킬은 작가공방 소버린 스튜디오의 독립 전문 모듈이다. 필요한 상황에서만 로드하며 전체 산문을 직접 작성하지 않는다. 실제 전체 Writer는 `novel-fiction-prose` 하나다.

## 핵심 원리
증상과 원인을 분리한다. “재미없다”, “늘어진다”, “AI 같다”, “캐릭터가 죽었다”는 진단명이 아니라 독자 증상이다. 이 스킬은 원고를 다시 쓰지 않고 **가장 상위의 실패 원인 한두 개를 찾은 뒤 가장 작은 개입 지점**을 지정한다.

## 진단 축
- **이야기 엔진**: 지금 독자가 무엇을 기다리고 있는가. 기다릴 것이 없다면 사건 추가보다 약속 부재가 문제일 수 있다.
- **인물 엔진**: 인물이 선택으로 사건을 바꾸는가, 아니면 작가가 정한 사건을 통과만 하는가.
- **압력 엔진**: 실패 비용·시간·관계·정보·자원 압력이 실제 결정을 바꾸는가.
- **의미 엔진**: 사건들이 같은 질문을 다른 각도에서 압박하며 누적되는가.
- **독서 엔진**: 이해·호기심·감정·예측 가능성의 균형이 깨지지 않았는가.

## 판단 절차
1. 사용자 최신 목표와 승인 본문을 먼저 잠근다.
2. 문제를 `concept / character / world / causality / pacing / dialogue / prose / ending / genre / continuity` 중 최대 두 축으로 분류한다.
3. 장면 하나의 문제인지 아크/작품 전체 문제인지 해상도를 판정한다.
4. 이미 존재하는 더 전문적인 Skill로 넘길 수 있으면 직접 해결하지 않고 라우팅한다.
5. “전부 갈아엎기”보다 원인 하나를 고쳤을 때 여러 증상이 동시에 줄어드는 레버를 우선한다.

## 출력
`증상 → 근본 원인 후보 → 근거 장면/상태 → 가장 싼 검증 방법 → 추천 Skill → 보존해야 할 장점` 순서로 전달한다.

## 경계
취향을 오류로 만들지 않는다. 조용한 장면, 짧은 대사, 느린 호흡 자체는 결함이 아니다. 진단의 목적은 스타일을 평균화하는 것이 아니라 작품이 스스로 약속한 효과를 더 정확히 내게 하는 것이다.

## 입력 계약
현재 승인 본문, 사용자 최신 지시, 필요한 상태/정사 자료 중 이 판단에 직접 필요한 것만 받는다. 다른 전문가의 취향성 평가나 결론을 사실처럼 상속하지 않는다.

## 인계
Writer에게는 실패 목록을 장황하게 주입하지 않고 **긍정적으로 쓸 수 있는 사실·제약·목표**만 넘긴다. 검수 단계에서는 정확한 구간과 독자 효과를 finding으로 넘긴다.

## 완료 기준
이 전문영역 때문에 다음 선택이 달라지는 핵심 정보가 정리됐고, 불필요한 전면 재작성이나 다른 Skill 책임 침범 없이 인계됐으면 종료한다.
