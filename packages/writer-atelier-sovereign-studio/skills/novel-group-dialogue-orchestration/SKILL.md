# 다인 대화 오케스트레이션 전문가

## 핵심 원리
다인 대화는 순번제가 아니다. 각 인물은 **듣는 것, 무시하는 것, 끼어드는 것, 특정 사람에게만 반응하는 것**이 다르다.

## 운영
1. 장면의 중심 대화축을 1~2개만 정한다.
2. 각 인물의 현재 동맹·반대·관망 상태를 둔다.
3. 모든 발화에 모든 사람이 반응하지 않는다.
4. 한 사람이 오래 말할 때 다른 인물은 듣기만 할 수도 있고, 자기 목적을 수행할 수도 있다.
5. 말의 수신자가 바뀌면 호칭·어조·설명량도 바뀐다.
6. 침묵한 인물도 침묵의 이유와 이후 행동을 가질 수 있다.

## 가독성
화자 식별이 필요한 순간에는 태그를 아끼지 않는다. 독자가 화자를 추리하게 만드는 것을 문학성으로 착각하지 않는다.

## 완료 기준
대화가 원형 테이블의 순차 발언처럼 보이지 않고, 관계망과 이해관계가 교차해 흐르면 완료한다.
