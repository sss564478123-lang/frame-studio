# 검수 프로필 선택표 — Sovereign Studio

| 프로필 | 활성 관점 | 사용 조건 |
|---|---|---|
| LIGHT | 구조, 캐릭터/대사, 신규독자, 필요시 장면전환 + 편집장 | 일반 회차 |
| CANON_AU | LIGHT + 정사/AU + 연속성/세계 + 필요시 적대자 지능 | 패러디/AU |
| SERIAL | LIGHT + 장기독자 + 연재리듬 + 진행경제/세계반응 | 장기 웹연재 |
| MYSTERY | 신규독자 + 정보통제 + 미스터리 공정성 + 인과 + 편집장 | 미스터리/반전 |
| ACTION | 몸/공간 + 적대자 지능 + 인과 + 성장밸런스 + 캐릭터 | 전투/추격/능력전 |
| ENDING | 구조 + 장기독자 + 결말회수 + 인과 + 복선/연속성 | 권말·아크 종료 |
| CROSSOVER_CRITICAL | CANON_AU + 장르 + 인과 + 세계논리 | 복수 정사 교차 |
| RELEASE_CRITICAL | 독립 reviewer 17명 + 편집장 | 최종 공개·대형 클라이맥스 |

프로필은 품질 등급이 아니라 오류 비용과 작품 유형에 맞춘 비용 제어다. 일반 회차에 full council을 남용하지 않는다.
