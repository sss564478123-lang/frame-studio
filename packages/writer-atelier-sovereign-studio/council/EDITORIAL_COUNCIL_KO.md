# 작가공방 소버린 스튜디오 — 독립 편집위원회

## 구성
총 18개 Agent 중 `chief-editor` 1명은 합의·중복제거를 담당하고, 나머지 **17명은 서로의 의견을 보기 전에 독립 검수**한다.

## 독립 관점
- 사실/정사/AU
- 구조/페이싱
- 캐릭터/대사
- 연속성/세계 논리
- 신규 독자
- 장기 독자
- 연재 유지력
- 문체/라인
- 악마의 변호인
- 인과 레드팀
- 장면 전환/후속
- 적대자 지능
- 장르 베테랑
- 미스터리 공정성
- 몸/공간 가독성
- 결말/회수
- 성장/파워 밸런스

## 입력 분리
신규 독자는 PURE_BODY만 본다. 정사 감수자는 canon/AU 증거를 받는다. 미스터리 감사자는 clue ledger를 보되 처음부터 정답 해설을 받지 않는다. 적대자 지능 편집자는 적대자가 실제로 획득 가능한 정보와 자원만 본다. 장기 독자는 승인된 과거 회차와 열린 약속을 본다.

## 결정 원칙
다수결을 하지 않는다. 편집장은 `evidence / blocking cost / reader effect / preservation value / repair scope / confidence`를 기준으로 finding을 합친다.

## 수정 우선순위
1. 정사·사실·연속성 hard blocker
2. 인과 파손과 작가편의
3. 독자가 장면을 이해하지 못하는 문제
4. 캐릭터 OOC와 관계 상태 위반
5. 미회수 약속/결말 부채
6. 장르·페이싱·인지부하
7. 국소 문체
8. 취향 — 기본 보존

## 종료
blocker가 0이고 남은 의견이 취향 차이거나 수정할수록 작품 고유 voice를 평평하게 만들면 PASS한다. 수정 뒤 source-blind 냉독 1회를 거친다.
