# 런타임 흐름 — 작가공방 소버린 스튜디오

## 기본 원칙
50개 Skill과 18개 Agent는 **카탈로그**다. 한 요청에 전부 로드하지 않는다.

## 일반 오리지널 회차
`router → (필요시 story-sense) → series/arc/genre/world 중 최소 집합 → state/scene/character/dialogue → fiction-prose → LIGHT council → local repair → release → dossier`

## 패러디/AU
`router → canon-research + parody-au-architect → 필요시 world-response / antagonist-counterplay → state/character/scene → fiction-prose → CANON_AU council → release`

## 크로스오버
`router → 각 canon-research + crossover-harmonizer + world-systems → character-distinctness / knowledge control → fiction-prose → CROSSOVER_CRITICAL council`

## 장기 연재
`router → series-architect + foreshadowing-payoff + subplot-weaving + progression-economy + world-response-escalation 중 필요한 것 → episode experts → fiction-prose → SERIAL council`

## 미스터리/스릴러
`router → suspense-information + mystery-fair-play + reader-cognitive-load → scene/character → fiction-prose → MYSTERY council`

## 액션/배틀
`router → action-choreography + sensory-embodiment + antagonist-counterplay + progression-economy(성장물이면) → fiction-prose → ACTION council`

## 결말/아크 종료
`router → reverse-outline + ending-payoff + foreshadowing-payoff + character/relationship arc → fiction-prose 또는 국소 reviser → RELEASE_CRITICAL council`

## 장편 대수술
`story-sense → reverse-outline → developmental-revision → 영향 지도 → 필요한 상위 구조 수정 → 장면 수정 → 마지막에만 prose reviser`

모든 경우 전체 Writer는 하나다. Critic finding을 초고 Writer에게 그대로 주입하지 않는다.
