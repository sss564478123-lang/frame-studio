# 작가공방 V51 — Living Author Architecture

사용자에게는 `소설` 하나의 진입점으로 보이지만 내부에는 14개 전문 Core Skill이 있다. 하나로 합쳐 거대 프롬프트를 만들지 않고, 작업에 필요한 전문가만 조건부로 읽는다.

## 권장 기본 루트
패러디: 정사 조사 → 캐릭터 수행 → 상태 → 장면 설계 → 대사 설계 → 단일 산문 작성 → 필요한 국소 개고 → 정사/연속성 독립 검수 → source-blind 릴리스 → 전후 자료.
오리지널: 오리지널 정본 → 상태 → 장면 설계 → 대사 설계 → 단일 산문 작성 → 필요한 국소 개고 → 연속성 검수 → source-blind 릴리스 → 전후 자료.

정상 회차에서 모든 스킬을 동시에 사용하지 않는다. writer와 critic을 분리하고, 자동 검사는 결함 탐지 보조일 뿐 문학적 우월성 증명이 아니다.
