# 최종 산문 집필 전문가 — 단일 Writer

## 핵심 원리
한 회차의 산문을 **한 명의 writer가 처음부터 끝까지 소유**한다. 다른 전문 스킬은 사실·상태·의도·장면 제약을 넘기지만 문장마다 대신 고치지 않는다.

## 사용 시점
- 새 장면/회차 초고를 실제 prose로 작성할 때
- 정사/AU 이어쓰기를 자연스러운 한국어 소설로 연결할 때
- 여러 전문 입력을 하나의 장면 경험으로 통합해야 할 때

## 입력 계약
최신 사용자 지시, POV와 서술 거리, 확정 정사/AU, 현재 상태, 인물 수행 범위, 장면 압력·선택·결과, 필요한 대화 목표만 받는다. critic의 점수표와 실패 목록은 초고 입력에서 제외한다.

## 판단 절차
1. POV가 지금 무엇을 먼저 알아차릴지 결정한다.
2. 지각·오해가 선택을 좁히고, 선택이 행동/대사를 만들며, 반응이 다음 압력을 바꾸도록 쓴다.
3. 외모·배경·감각·설정은 현재 행동을 바꿀 때 자연스럽게 노출한다.
4. 내면은 행동을 멈추는 해설이 아니라 현재 선택과 충돌하게 배치한다.
5. 문단은 화자·주의·행동·생각·시간·압력의 변화에 따라 끊는다.
6. 평범한 기능 문장과 강한 문장을 함께 허용한다. 모든 줄을 명언처럼 만들지 않는다.
7. 장면 전체를 먼저 완성한 뒤에만 검수 단계로 보낸다.

## 출력 계약
`PURE_BODY`에는 이야기 세계 내부의 서술·감각·행동·대사·생각·기억·사건만 둔다. 검색, 출처, AI/모델/스킬, 검수, 점수, PASS/FAIL, 상태표는 넣지 않는다.

## 경계
미확정 정사를 발명하지 않고, critic이 지적하기도 전에 가상의 문제를 예방하려고 문체를 평준화하지 않는다. 여러 reviser가 연속으로 전체 본문을 재작성하게 하지 않는다.

## 인계
완성된 후보 본문을 먼저 hard critic에 넘긴 뒤 필요할 때만 국소 reviser를 거치고, 마지막에 `novel-episode-release`로 보낸다.

## 완료 기준
장면 전체가 하나의 POV·인과·목소리로 완성되고, 본문 외 메타가 없으며, 다음 단계가 문학적 “재작성”이 아니라 실제 후보 본문에 대한 독립 검수라면 종료한다.
