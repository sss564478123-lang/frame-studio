# GitHub 구조 원칙 참고 기록

V51.1은 외부 프롬프트를 통째로 복사한 패키지가 아니라 공개 GitHub의 작법·스킬 설계 원칙을 비교해 기존 작가공방 계약에 맞게 재구성했다.

- SkillMedev `fiction-writers-room`의 Fiction Scene Writer: 장면을 실시간 사건으로 다루고 감각 세부를 목록이 아니라 선택적으로 사용하는 원리.
- SkillMedev Ghostwriter: 중립적인 모델 house style로 평준화하지 않고 작가/인물의 리듬과 register를 보존하는 원리.
- SkillMedev Manuscript Reviser: 전체 passage를 먼저 읽고 coarse-to-fine으로 수정하며 이미 작동하는 문장을 건드리지 않는 원리.
- jwynia `agent-skills` Dialogue: 동일 음성, 정보 전달형 대사, Tennis Match식 균등 교대, subtext/context 진단 원리.
- Superpowers `writing-skills`: 스킬 설명을 사용 조건 중심으로 쓰고, 거대한 단일 스킬보다 책임 경계가 분명한 독립 스킬과 검증을 선호하는 원리.

외부 자료는 구조·진단 원칙만 참고하며 저작권 소설의 원문 장면·대사를 런타임 예제로 저장하지 않는다.
