# 작가공방 V51.1 — 플러그인 설치용 전문가 스킬 번들

이 폴더는 **소설 스킬 하나에 모든 규칙을 합치지 않고**, 총괄 라우터 1개와 전문 스킬 14개를 평면 구조로 분리한 설치용 번들이다.

핵심 목표는 “규칙이 많은 소설 엔진”이 아니라 **한 명의 writer가 살아 있는 장면을 쓰고, 조사·상태·검수 전문가는 필요한 순간에만 개입하는 구조**다.

## 구성
- `skills/novel-router` — 총괄 진입점
- `skills/novel-*` — 14개 전문 스킬
- `PROJECT_INSTRUCTIONS_KO.md` — 소설 프로젝트에 넣을 고정 계약
- `SKILL_CATALOG_KO.md` — 한국어 역할표
- `INSTALL_KO.md` — 설치 방법과 권장 활성 방식
- `evals/regression-scenarios.md` — 회귀 평가 시나리오

## 불변식
사용자 최신 지시와 승인 본문이 최상위다. 정사/AU는 분리한다. 승인 본문이 파생 장부보다 우선한다. 정사 기반 작품의 필수 값이 없으면 임의로 채우지 않는다. 기본 회차는 `본문 전 자료 → 순수 소설 본문 → 본문 후 자료`이며 PURE_BODY에는 제작 메타를 넣지 않는다. 초고 writer와 critic을 분리한다.
